# Repository instructions

- Use parallel subagents for independent checks; keep reports concise.
- For wavy-underlined research contributor links, use `inline-block leading-snug` with the existing underline class, matching the research-title text box. Plain inline links can place the wave against the glyphs, especially at `text-xs`.
- When changing wavy-link typography, visually compare the advisor link with the Yelp research title on localhost. Check normal and hover states in light and dark mode; keep a visible gap beneath the letters and descenders. Do not change global wave positioning to fix one link.
